# Jellyfin Holz-Theme

Ein warmes, dunkles Theme im Holz-Look mit Honig-Akzenten für Jellyfin.

## Installation

1. Im Jellyfin-Dashboard zu **Einstellungen → Branding** gehen.
2. Im Feld **Benutzerdefiniertes CSS** diese Zeile einfügen:

   ```css
   @import url("https://cdn.jsdelivr.net/gh/DEIN-USERNAME/jellyfin-wood-theme@v1.0.0/theme.css");
   ```

3. Speichern und die Seite mit Strg + F5 neu laden.

## Versionen

Die Version steht im Tag (z. B. `v1.0.0`) in der URL. Für Updates die Versionsnummer in der URL anpassen.
